

# Sleep Health & Lifestyle Dashboard

Interactive Excel dashboard analyzing the Sleep Health and Lifestyle dataset.

## Features
- KPI cards (Total People, Avg Sleep Duration, Avg Sleep Quality, Avg Stress, % with Sleep Disorder)
- Average Sleep Duration by Occupation
- Sleep Disorder Distribution (Donut Chart)
- Stress Level vs Sleep Quality
- Sleep Disorders by BMI Category
- Interactive Slicers (Gender, Occupation, BMI Category, Sleep Disorder)

## How to use
1. Download the `.xlsx` file
2. Open it in Excel
3. Use the slicers to filter the dashboard

## Data Source
https://www.kaggle.com/datasets/uom190346a/sleep-health-and-lifestyle-dataset
